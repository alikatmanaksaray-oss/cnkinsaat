# CNK İnşaat – Netlify Yönetim Paneli

Yönetim paneli: https://cnkinsaat-kiy0.netlify.app/admin/

## İlk kurulum (bir kez)

1. Netlify'da Identity ayarlarını aç: https://app.netlify.com/projects/cnkinsaat-kiy0/identity
2. Enable Identity seçeneğini etkinleştir.
3. Registration bölümünde kayıt yöntemini Invite only yap. Herkese açık kayıt bırakma.
4. Services bölümünden Git Gateway seçeneğini etkinleştir.
5. Users bölümünden yalnızca yetkili yönetici e-posta adresini davet et.
6. Davet kabul edildikten sonra /admin/ adresinden giriş yap.

## Yönetim panelinde düzenlenebilenler

- Site iletişim bilgileri, sosyal medya adresleri ve anasayfa istatistikleri
- Açılış duyurusu ve kampanya metni/görseli
- 13 projenin adı, açıklaması, konumu, durumu, kapak fotoğrafı ve galeri fotoğrafları
- Galeri videoları
- E-katalog kayıtları ve PDF yüklemeleri
- Sıkça sorulan sorular
- Hizmetler
- KVKK, Gizlilik Politikası ve Kullanım Şartları

Değişiklikler GitHub main dalına kaydedilir ve Netlify yeni sürümü otomatik yayınlar.

Güvenlik: Identity kayıtlarını Invite only tutun ve yalnızca güvendiğiniz yönetici hesaplarını davet edin.
